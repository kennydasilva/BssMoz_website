# BSS — Better Steel Solutions

Site institucional da BSS (Better Steel Solutions), fornecedor de metais e
materiais de construção em Moçambique. Construído em React + TypeScript com Vite.

Conteúdo bilingue (PT/EN), catálogo de produtos filtrável por família e
material, e formulário de pedido de cotação.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

## Lint

```bash
npm run lint
```
